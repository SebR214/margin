Each agent has one job and cannot do the others'

The builder cannot merge its own work. The reviewer cannot write features. The planner never writes code.

  • CollectorEvery hourPulls prices from exchanges, Binance P2P and providers, and writes them to the data files.
  • BuilderOne task per runBuilds exactly one task, then stops. If a task would break a rule, it refuses and flags it.
  • ReviewerEvery changeChecks each change against one question: would this survive a payments expert checking one figure by hand?
  • PlannerBetween buildsDecides what gets built next, and reports what happened. Never writes code, never merges.

Seb approves four things. The agents ship everything else on their own.

  • Deleting anythingA page, chart, table or number cannot disappear without approval.
  • A new published numberAny new way of measuring something.
  • The site's thesisWhat VISION.md says the site argues.
  • Money and accessSpending, credentials and identity.

When the agents got it wrong, and the rule each mistake left behind

  • A collector ran for 34 days and recorded nothingIt pointed at a hostname that didn't exist. Rule: no collector goes live until it has run once by hand, and silence counts as a failure.
  • A paid key ran the whole system for twenty minutesA config change put the metered key where the agents' flat-rate key belonged, and it spent real money before anyone noticed. Rule: the two keys live in separate files that cannot be merged.
  • 21 hours of prices were lost for goodA new data file was not on the list of files to save, and the whole pipeline stopped. Rule: every file is named in the save step, and anything missed is caught and saved with a warning. The gap stays visible in the history.
  • No price is an answer tooNobody is selling dollars in Ethiopia right now, so Ethiopia shows "no price" and the reason, instead of a guess.
